# Upload MotoService Lite to GitHub — simple steps

1. Sign in to GitHub and go to https://github.com/new .
2. Owner: `yusufthecoder474`; repository name: `MotoService-Lite`; visibility: Public. Do **not** tick “Add a README,” “Add .gitignore,” or “Choose a license.” Create the repository.
3. The easiest reliable method for a full project is **GitHub Desktop** (https://desktop.github.com/). Unzip this project, open GitHub Desktop → File → Add local repository → choose the `motoservice-lite` directory. If it says the folder is not a Git repository, choose **Create a repository here**.
4. Review the changes and ensure you do not see `target/`, `.env`, or local logs. Commit as `Initial public release: MotoService Lite`.
5. Click **Publish repository**, choose `MotoService-Lite` and uncheck **Keep this code private**.
6. Open https://github.com/yusufthecoder474/MotoService-Lite and verify the README images and links render. Test in an incognito window.

If the repo already exists remotely, do not create a second unrelated repository: use the same GitHub repository and check its existing history before publishing.
